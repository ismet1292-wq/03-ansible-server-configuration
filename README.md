# Ansible Server Configuration

A DevOps portfolio project demonstrating automated server configuration using Ansible.

## Project Overview

This project uses Ansible to configure a Linux server and install the Nginx web server.

The playbook was tested locally using Ubuntu on WSL2.

## Technologies

- Ansible
- Ubuntu Linux
- WSL2
- Nginx
- Git
- GitHub
